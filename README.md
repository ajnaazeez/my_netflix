# Netflix UI Clone 

This project is a front-end clone of the Netflix landing page created for practice and to improve my web development skills. The interface is designed to closely resemble the official Netflix website layout.

##  Features
- Fully responsive design
- Modern UI similar to Netflix
- Navigation bar with logo and buttons
- Hero section with background banner
- Movie/Show sections with cards
- Hover effects and smooth layout
- Mobile friendly using Bootstrap grid system

## 🛠️ Technologies Used
- HTML5
- CSS3
- Bootstrap 5

##  Purpose of the Project
This project was built to practice front-end development concepts such as:
- Responsive design
- Layout structuring
- Flexbox & Grid
- Bootstrap components
- UI replication
